# Start the heading 1.25rem down at 64rem and wider

At min-width 64rem, main's top margin is 1.25rem, so the name and the h1 begin near the top.

Keeping 3.75rem at that width wasted the first screen on a 768px-tall laptop and hid the first checkbox.

The name label is the first painted text, about 1.25rem below the viewport edge.
