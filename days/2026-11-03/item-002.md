# Keep the first checkbox inside an 800px-tall window

The checkbox for the first-screen task has to be visible before any scroll when the window is 800px tall.

The heading is 2rem with a 1.2 line height, and the date plus the bilingual sentence take the next two blocks, so a taller heading would push that first checkbox under the fold.

On a 1366 by 768 screen the first checkbox still clears the bottom of the viewport by a small margin.
